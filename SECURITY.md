# Security Policy

## Reporting a vulnerability

If you believe you have found a security vulnerability in `go-semver`, please
**open a public issue** and we will make the required changes.

Please include enough information to reproduce the issue (affected version,
steps, and impact) so we can triage it quickly. We will acknowledge your report
and keep you informed of the resolution.

Thank you for helping keep `go-semver` and its users safe.
